Assistance

De l'aide avec Plume.

Obtenir de l'aide

  • Bugs, questions et idées : ouvrez un ticket sur GitHub.
  • Sécurité : si vous trouvez une faille, n'en publiez pas les détails dans un ticket public : signalez-la en privé sur GitHub.

Avant d'écrire, la FAQ et le README ont peut-être déjà la réponse.

Que mettre dans un rapport de bug

  • La version de Plume (ou le commit compilé) et celle d'iOS, d'iPadOS ou de macOS.
  • La version de votre serveur Nextcloud, si vous la connaissez.
  • Les étapes qui mènent au problème, et ce que vous attendiez.
  • Jamais votre mot de passe, votre mot de passe d'application ni l'adresse de votre serveur dans un ticket public : écrivez cloud.example.com à la place.

Réponses rapides

La connexion n'aboutit pas

Avec le Login Flow, Plume attend que vous vous soyez connecté et que vous ayez autorisé l'accès dans la page ouverte dans le navigateur. Si le navigateur affiche une erreur, vérifiez que l'adresse est bien celle que vous utilisez sur le web (par exemple cloud.example.com, ou cloud.example.com/nextcloud si le serveur est installé dans un sous-dossier). Vous pouvez aussi vous connecter avec un mot de passe d'application, créé dans Nextcloud sous Paramètres → Sécurité.

Où trouver Plume dans le Finder ou l'app Fichiers ?

Sur Mac, Plume apparaît dans la barre latérale du Finder, sous Emplacements. Sur iPhone et iPad, ouvrez Fichiers, touchez Parcourir : Plume figure dans les Emplacements ; sinon, touchez ⋯ → Modifier et activez-le.

Une modification faite sur le web n'apparaît pas encore

Les changements faits ailleurs arrivent dans Plume, le Finder et Fichiers quand Plume est ouvert ; il n'y a pas encore d'actualisation en arrière-plan. Ouvrez Plume, et le dossier se met à jour.

Un fichier envoyé a changé de nom

Plume n'écrase jamais un fichier à l'envoi : si le nom est déjà pris, le nouveau fichier est enregistré sous « nom 2.ext ».
