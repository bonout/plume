Au quotidien

Vos fichiers, sans attendre.

Une app SwiftUI native, sans aucune dépendance tierce. Elle parle les protocoles standard de Nextcloud (WebDAV et OCS) : elle fonctionne avec le serveur que vous avez déjà.

Recherche

Trouvez un fichier en quelques lettres.

Plume tient un index local de tous les fichiers et dossiers de votre compte : les résultats s'affichent à chaque lettre, quel que soit le dossier. Majuscules et accents n'y changent rien : « resume » trouve « Résumé.pdf ».

Vos fichiers remontent aussi dans Spotlight sur iPhone, iPad et Mac : un résultat ouvre Plume directement sur le fichier.

    Comment ça marche

    Connectez-vous une fois. Ensuite, ce ne sont que des fichiers.

    1. ConnexionSaisissez l'adresse de votre serveur et autorisez Plume dans le navigateur avec le Login Flow de Nextcloud (la double authentification fonctionne), ou utilisez un mot de passe d'application.
    2. Navigation et recherchePlume liste vos dossiers, indexe leurs fichiers, puis garde cette copie à jour depuis le serveur.
    3. PartoutOuvrez vos fichiers dans le Finder ou Fichiers, enregistrez dans Nextcloud depuis n'importe quelle app, gardez hors ligne ce dont vous avez besoin.
    Confidentiel par conception

    Vous et votre serveur, personne d'autre.

    Plume n'a pas de compte à lui, pas de statistiques d'usage, aucun pistage. L'app ne parle qu'à votre serveur Nextcloud.

    • Aucun serveur tiers : chaque requête va au serveur Nextcloud auquel vous vous connectez.
    • Trousseau : le mot de passe d'application est rangé dans le trousseau.
    • Révoqué à la déconnexion : en vous déconnectant, Plume révoque aussi le mot de passe d'application sur votre serveur.
    • Protocoles standard : WebDAV et OCS, tels que Nextcloud les documente. Aucune extension à installer sur le serveur.
    • Aucune dépendance : uniquement les frameworks d'Apple, pas de code tiers dans l'app.
    • Open source : GPL-3.0 ou ultérieure, tout le code sur GitHub.
